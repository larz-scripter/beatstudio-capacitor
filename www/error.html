Can’t reach larzos.com

The studio itself is almost certainly fine — this device just can’t open a connection to it. It is usually the network you are on, not the app.

If it keeps failing on this network

Some mobile carriers drop traffic to certain Cloudflare addresses. When that happens the site answers normally for everyone else while this phone times out. Changing the phone’s DNS fixes it:

  1. Android Settings → Network & internet → Private DNS
  2. Choose Private DNS provider hostname
  3. Enter dns.google  (or dns.quad9.net)
  4. Save, then reopen BeatStudio

Do not set it to one.one.one.one — that resolver is the one that hands out the unreachable addresses.

Mobile data and Wi-Fi can behave differently, so trying the other one is also worth a go.
